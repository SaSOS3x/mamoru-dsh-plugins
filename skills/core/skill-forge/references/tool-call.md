# Как навык вызывает свой скрипт

При загрузке навыка DSH показывает модели строку

```
Base directory for this skill: <путь к папке навыка>
```

и велит решать относительные пути от неё. Отдельной переменной вида `CLAUDE_SKILL_DIR`, которую
подставлял Claude Code, в DSH нет, поэтому в тексте навыка пиши путь относительно папки навыка:

```
python scripts/x.py аргументы
```

- Интерпретатор пишется явно (`python`, не голый путь к скрипту и не `python3`: на Windows
  `python3` часто заглушка Microsoft Store).
- Кавычки вокруг пути нужны, если в пути возможны пробелы; для относительного пути с одним
  слашем их можно не ставить.
- Если скрипт печатает не только ASCII, пусть он сам переключит вывод на UTF-8
  (`sys.stdout.reconfigure(encoding="utf-8")`), или вызывай его с `-X utf8`. Флаг `-I` отключает
  переменные `PYTHON*`, в том числе `PYTHONIOENCODING`, поэтому `python -I` без `-X utf8` на
  Windows печатает в cp1251.
- Если команда меняет рабочий каталог, относительный путь перестанет работать: сначала перейди в
  папку проекта, потом вызывай скрипт по полному пути навыка или задай путь переменной.

Проверка после правки навыка: открой новую сессию, загрузи навык и посмотри, что в заголовке
`Base directory for this skill` стоит папка, в которой лежит SKILL.md; запусти скрипт по тому же
относительному пути из папки проекта.

## Где лежит навык

Папку навыка определяет способ установки, поэтому угадывать её из текста нельзя. В этом порте два
способа, и оба описаны в `install.ps1`:

| Как установлен | Откуда читается навык | Меняется ли путь |
|---|---|---|
| `powershell -NoProfile -File install.ps1` (по умолчанию) | `%USERPROFILE%\.dsh\skills\<навык>` - junction на папку `skills\<навык>` этого репозитория | нет: правишь репозиторий, установка видит правку сразу |
| `powershell -NoProfile -File install.ps1 -Copy` | копия папки в `%USERPROFILE%\.dsh\skills\<навык>` | нет, но правку репозитория нужно копировать заново (`-Copy -Force`) |
| Навык подключён через `customSkillDirs` в профиле | папка репозитория, указанная в конфигурации | нет |

Для проверки, какой путь загрузился, сверяй заголовок `Base directory for this skill` с
`install.ps1 -List`: у junction он может показывать как путь ссылки, так и путь цели - это одна и
та же папка.

Если навык правится прямо в репозитории, а сессия открыта с копией, правка не видна: сравни дату
`SKILL.md` в установке и в репозитории и обнови установку. После правки описания навыка каталог
сессии обновится сам, после правки текста - загрузится при следующем вызове `skill`.
