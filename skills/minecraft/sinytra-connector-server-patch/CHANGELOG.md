# CHANGELOG: sinytra-connector-server-patch

## 2026-11-14 | Первая версия

Что: навык создан из задачи «серверный патч Sengoku 2.1.5 для NeoForge 21.1.264 + Sinytra Connector
без клиентского `sengoku_patch`». Вошли: диагностика по `debug.log`, архитектура
`ITransformationService` + `ITransformer`, замена accessor'а по эразу, новые классы GAME-ресурсом,
сборка через `patchclasses`, изолированный стенд и sidecar с exit code, таблица ловушек, раздел про
шум `Detected setBlock in a far chunk` и DSBG.

Почему: задача заняла ~3 часа и четыре агента; главные находки (ILaunchPluginService из `mods/` не
грузится; конфиг миксинов берётся из mapped-кэша; accessor надо заменять, а не удалять; новые классы
только GAME-ресурсом) не выводятся из существующих навыков про порт модпаков.

Проверено: 6 прогонов на копии сервера и боевом сервере, сессия игрока 35 минут, контроль/фильтр
DSBG на 729 чанках (30 683 → 0), проверяющий агент нашёл ложные PASS в приёмочных скриптах и они
исправлены. Журнал: `skills-lab/sinytra-connector-server-patch/JOURNAL.md`.

## 2026-11-14 | Правки после проверок

Что: `javap` в §3 теперь только по `neoforge-21.1.264-server.jar` (с `srg.jar` первым виден
ванильный `Monster`, а рантайм - `Mob`); префикс ресурсов `patch/` заменён на фактический
`sengoku_server_patch/`; «кэш не патчить вообще» смягчено до «не патчить во время запуска»;
C2ME назван контекстом, а не причиной шума; добавлены числа боевого мира (30 723) и список 13 классов.

Почему: повтор задачи чистым исполнителем и проверка фактов по jar'ам нашли 6 неточностей, из них
две вели к неверным действиям (javap не тот classpath, неверный путь ресурсов).

Проверено: `check_skills.py` - 19 навыков, 0 замечаний; проверяющий агент подтвердил остальные
пункты по `debug.log`, `MixinInfo`, `ClassTransformer`, `DsbgWorldGenMixin`.
